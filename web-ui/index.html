Apigee X + Keycloak + ADK Architecture Zero-Trust Tool Governance
Step 1
3 User Tiers & UI
Public: anonymous chat. Customer & Store Manager: authenticate with Keycloak via 3-legged OAuth popup.
Step 2
Keycloak OAuth 2.0
Issues signed JWT tokens with role claims (biscuit_coffee_customer or biscuit_coffee_manager).
Step 3
Google ADK Agent
Gemini plans tool calls and invokes Apigee MCP Tools, passing user Bearer JWT or anonymous headers.
Step 4
Apigee Proxies & Gating
MCP Proxy (/mcp): Transcoding & ParsePayload (PP-ParseMCPTools).
Biscuit-Coffee Proxy: JWT-VerifyToken & Scope checks (Allow 200, Reject 401/403).
Step 5
Cloud Run Backend
Delivers backend business responses for menu, loyalty balance, coffee orders, and staff directory.
